Les balises de base

Balises de base : 

<h1>, <p>, <a>, <img>, <ul>, <li>, etc.

<h1>

La balise <h1> est utilisé pour le titres de nos sections. Il y'a 6 niveaux en tout de <h1> à <h6>. <h1> correspond au titre principale de notre section. <h2> est un sous titre du titre. <h3> est un sous sous titre etc...

Voici à quoi cela ressemble :

Titre <h1>

Sous titre <h2>

Sous titre 2 <h2>

Sous titre 3 <h2>

Sous sous titre <h3>

Sous sous sous titre <h4>

Sous sous sous titre <h4>

Sous sous sous sous titre <h5>
Sous sous sous sous titre <h5>
Sous sous sous sous titre <h5>
Sous sous sous sous sous titre <h6>

Sous sous sous titre <h4>

<p>

La balise <p> est partout sur cette page ! Il sagit de la balise paragraphe. On l'utilise pour du texte baqique (comme vous êtes en train de lire en ce moment !).

Comme son nom l'indique, cette balise est utilisé pour séparer les paragraphes. Vous remarquerez qu'il y'a un espace entre ce paragraphe et le précedent. Je ne l'ai pas ajouter, cela s'est fait automatiquement car ce sont deux paragraphes distincts qui utilisents chacun leurs propre balise <p>.

<a>

La balise <a> sert pour les liens. On peut l'utiliser de cette facon : 

<a href="https://www.wikipedia.org/">Lien qui conduit sur la page wikipedia</a>

Ce qui donne : Lien qui conduit sur la page wikipedia.

href correspond au lien ou on veut envoyer l'utilisateur, dans ce cas, wikipedia. Il y'a toutes fois des règles de base à respecter lorsque l'on utilise la balise <a>. En général, lorsque l'on veut envoyer l'utilisateur sur une autre page du même site, on utilise la méthode du dessus. Mais lorsque l'on veut les envoyer sur un autre site, il est d'usage d'ouvrir le lien dans un autre onglet pour éviter de surprendre l'utilisateur et de lui faire perdre sa navigation (comme vous l'avez surement était avec l'éxemple du dessus !). Dans ce cas, on utilise : 

<a href="https://www.wikipedia.org/" target="_blank">Lien externe wikipedia</a>

Ce qui nous donne : Lien externe wikipedia.

Cette méthode est beacoup plus user friendly, et permet à l'utilisateur de reprendre là où il en était une fois qu'il à fini de consulter le site externe. Le target="_blank" est ce qui nous permet de dire que l'on veut ouvrir ce lien dans un nouvel onglet.
